# linux-basics

This repository is a beginner-friendly introduction to Linux basics.
It shares simple command-line examples you can use to navigate files,
inspect your system, and work more confidently in a terminal.

## Basic Linux Commands

- `pwd` — show your current working directory
- `ls` — list files and folders in the current directory
- `cd <directory>` — move into a different directory
- `mkdir <name>` — create a new directory
- `cat <file>` — display the content of a file
